# Weather Trend Analysis of Ghaziabad (2015-2024)

## Objective
To study how temperature and rainfall changed over time in Ghaziabad, and to find monthly and yearly patterns.

## Dataset
- **Source:** Open-Meteo Historical Weather API (daily data for Ghaziabad, 28.67°N, 77.42°E)
- **Variables:** max, min and mean temperature, rainfall, maximum wind speed
- **Changes made:** renamed columns, converted the date column, added `year`, `month`, `temp_range`, `is_rainy` and `temp_category`

## Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn, Excel, Google Colab, GitHub
